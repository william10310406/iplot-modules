# Changelog

「回報與討論」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [0.2.0] - 2026-11-07

回報會附上 iPLoT 面板最近的訊息；「回報問題」會附上最近一次的錯誤；預覽頁多一格「我當時在做什麼」與一顆「複製整份報告」。最近的訊息與最近一次的錯誤要 iPLoT 0.6.2；在 0.6.1 以前照 0.1.1 的樣子（只附環境資訊）。

### 新增
- 「最近的訊息」（D150）：iPLoT 0.6.2 的面板把最近一次的錯誤與那時候訊息區的最後 40 行寫進 `logs/last-error.json`。「回報這個問題」那一筆就是它的話，內文在「錯誤」後面多一節「最近的訊息」（最多 40 行、3000 字，跟其他地方一樣遮過）。網址放不下時，這一節先整節拿掉（完整的報告裡還有），再截 traceback。
- 「回報問題」附上最近一次的錯誤（D150）：有 `logs/last-error.json` 的話，「回報問題」不指定模組的那一份就是那一筆的回報，選單上寫「會附上最近一次的錯誤（時間）：標題」；沒有、讀不到、格式不對，照舊只附環境資訊。tkinter 面板的「1」也一樣，那一句寫在訊息區。
- 預覽頁「我當時在做什麼」：寫了字的話，放進「發生了什麼」底下（換掉「請寫一兩句」那一句），跟其他內容一起遮。
- 預覽頁「複製整份報告」：不開瀏覽器，只把遮過的全文複製到剪貼簿。沒登入 GitHub、或想貼到別的地方時用。

## [0.1.1] - 2026-11-05

送出前多一句明顯的提醒：這會公開在網路上，任何人都看得到，請先刪掉姓名、學號等個人資料。

### 變更
- 預覽頁在「在瀏覽器打開」正上方（紅框粗體）、tkinter 面板在確認框最前面，多一句「這會公開在網路上，任何人都看得到。送出前請自己再看一次，刪掉姓名、學號等個人資料。」字只在 `report.py` 的 `PUBLIC_WARNING` 寫一次（D120）。

## [0.1.0] - 2026-10-25

iPLoT 出錯時，錯誤訊息旁邊的「回報這個問題」會整理好版本與錯誤、先把家目錄、使用者名稱、路徑、學號遮掉給你看，再用瀏覽器開到 iPLoT 的 GitHub 討論區；面板上這一格可以回報問題、提建議、問問題、看論壇。不登入、不存密碼，送出在瀏覽器裡按。錯誤訊息旁邊那顆鈕要 iPLoT 0.6.0；在 0.5.x 上只有這一格的四個入口。

### 新增
- 回報這個問題（`on_error`，D110、D112、D113）：整理 iPLoT 的版本、作業系統、Python、出錯的模組與版本、traceback，遮過之後在預覽頁給你看、讓你改；按「在瀏覽器打開」時再遮一次（改過的字也遮），先把遮過的全文存進 `回報/`（檔名像 `20261025-143005-KeyError.txt`）、複製到剪貼簿，再用預填的網址開瀏覽器到「問題回報」分類，GitHub 出錯或內容被截斷時直接貼上。網址一律不超過 2000 字元：太長時先截 traceback 的中間，再截「發生了什麼」、內文的尾巴、標題；截過或瀏覽器打不開時（打不開就把網址給你複製），iPLoT 指出存好的那個檔（網頁面板等預覽頁關掉之後）。網址內文與預覽頁最後那一句，剪貼簿真的複製成了才說「完整報告已複製…按 ⌘V／Ctrl+V 貼上。」；沒複製成的話（剪貼簿裡可能是之前複製的、沒遮過的東西）改成「剪貼簿沒有複製成功：完整報告存在 iPLoT 的 回報/<檔名>；…從那個檔複製全文、直接貼上。」，也存不了檔時指預覽頁下面那一格（tkinter 面板指訊息區，遮過的全文也寫在那裡）。tkinter 面板沒有預覽頁，改成用編輯器打開草稿（`回報/` 裡的 `.md`），存檔、按「確定」才往下。
- 遮蔽（`redact.py`，D111）：家目錄、使用者名稱、路徑、疑似學號、電子郵件、下一層模組的名稱（例如學生的資料夾）都遮掉；iPLoT 自己與 Python 的 frame 留相對路徑與原始碼，其他 frame 的原始碼換成「（原始碼已略過）」。路徑包括沒有引號的絕對路徑、緊接在冒號後面的絕對路徑、`file://` 的網址，與引號裡的相對路徑：ASCII 的 `'` `"`、反引號、全形的 ＂ ＇、中文的「」『』“”‘’《》〈〉都算引號。遮過的再遮一次字一樣；預覽頁上方說遮了幾個。遮不到的幾種寫法在 iPLoT 的 `docs/08` 第 10.4 節。
- 四個入口（雙擊這一格，D114）：回報問題（沒有錯誤訊息的問題，可以選一個最上層的模組）、提建議、問問題、看論壇；tkinter 面板上問一次，輸入 1 到 4。論壇的網址與分類只寫在 `forum.py`（D115）。整個模組不連網（不 import 任何連網的套件，有測試核）、不登入、不存密碼或 token，只組網址交給瀏覽器。

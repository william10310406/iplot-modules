# Changelog

「課程作業」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。

## [0.1.0] - 2026-11-07

第一版：出作業的老師從範本寫一份作業、在 iPLoT 裡選一個 case 看結果、按「檢查與打包」得到學生包；學生在自己的電腦上照 README 跑。跟科目無關，核心一行都不改。

### 新增

- 面板上的格子：「新增一門課」「加入範例課程」，每門課有課那一格、「新增作業」「檢查與打包」，每份作業一格（資料夾補零，`HK1…HK12` 照數字排）。
- 規範 v2 的作業檔：殼叫 `coursework.py`，作業檔在老師、學生、助教三處都叫 `<代號>.py`，尾段三行、回結束碼（[docs/09](../../docs/09_作業規範.md)）。
- 在 iPLoT 裡按作業那一格：列出 case、打號碼跑一個（0 全部）、另開程序；`NOTE`、`DOCS` 放在第一個文字視窗；開始跑之前就出錯時另開文字視窗放錯誤訊息；課的 `.venv` 一律有 matplotlib，萬一開不了視窗，結果與錯誤放在訊息區。
- `--check`：R1–R28，規則表與 `docs/09` 同一份。在 iPLoT 裡只提醒，「檢查與打包」時擋。
- 每門課一個 `.venv`，套件分批或依作業的 `REQUIRES` 裝，裝之前先問；`.venv` 壞了（建它的 Python 不在了）會說、問要不要清掉重建。
- 檢查與打包：`發出去的/<代號>_學生包.zip`（作業檔、殼、`<代號>Space/`、學生用的 README；macOS 一段、Windows 一段，Windows 未經實機驗證）。
- 版本：作業資料夾的 `.版本/` 存每次打包出去的 zip（不自動刪）與每次按作業那一格時的 `.py`（最新 20 份）。
- 範本與範例課程「科學計算」（HK2、HK6、HK8）。

### 還沒有

- 舊格式（`import hk_page`）：不收，留在「科學計算」。

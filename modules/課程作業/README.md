# 課程作業

出作業的老師從範本寫一份作業、在 iPLoT 裡選一個 case 看結果、按一顆鈕打包成學生包；學生拿到 zip，照裡面的 README 在自己的電腦上跑。跟科目無關：一門課是 `modules/課程作業/` 底下一個有 `課程.py` 的資料夾。

這一版（0.1.0）做到「老師寫 → 老師看 → 打包 → 學生跑」。收作業、匯入作業、給沒有 iPLoT 的助教的批次包還沒有。Windows 未經實機驗證。

## 面板上的樣子

```
課程作業
├─ 新增一門課
├─ 加入範例課程
└─ <課的名字>              ← 按下去：把這門課要的套件裝進課自己的 .venv
   ├─ 新增作業
   ├─ 檢查與打包
   ├─ HK1                  ← 每份作業一格，按下去選一個 case 看結果
   ├─ HK2
   └─ …
```

按「課程作業」本身會在訊息區列出這台電腦上的課，每門一行：幾份作業、`.venv` 建了沒有。

## 開一門課

- **新增一門課**：問課的名字，建 `modules/課程作業/<課的名字>/`，裡面是一份只有 `NAME` 的 `課程.py`，加上課那一格與「新增作業」「檢查與打包」兩顆鈕。其他設定都有預設值，所以不用打開 `課程.py` 也能用。
- **加入範例課程**：把 `範例課程/科學計算/`（三份已經照規範寫好的作業 HK2、HK6、HK8）複製成一門課，用來看一份寫好的作業長什麼樣。已經有同名的課就不蓋。

要改作業代號的格式（預設 `HK1`、`HK2`…）、分批裝套件，才需要打開 `課程.py`；每個名字的意思寫在檔裡的註解，完整的表在 [docs/09_作業規範.md](../../docs/09_作業規範.md) 與設計文件的第 3 節。`課程.py` 只放字面值：iPLoT 讀它，不執行它。

## 新增作業

在課底下按「新增作業」，打作業代號（預設是課裡最大的號碼加 1）。iPLoT 從範本建 `<作業資料夾>/<代號>.py` 與一個空的 `<代號>Space/`（放資料檔），並用編輯器打開 `<代號>.py`。作業資料夾的名字補零（`HK01`…），這樣面板上 `HK1…HK12` 照數字排。

作業檔的寫法照 [docs/09_作業規範.md](../../docs/09_作業規範.md)：改「# ── 從這裡開始是作業 ──」和「# ── 以下不用改 ──」兩行中間的部分就好。

## 在 iPLoT 裡看結果

1. 第一次按課那一格：問要不要建這門課的 `.venv`、裝什麼，確定才做。套件只裝進 `<課>/.venv`，不裝進電腦本身的 Python。建 `.venv` 的 Python 後來被移掉或升了版，`.venv` 就壞了：按課那一格或作業那一格會說「壞了」、問要不要清掉重建，確定了才清掉、重建、重裝套件。
2. 按一份作業：列出它的 case，打號碼跑一個，打 0 全部跑。結果另開 Python 的視窗（在 Dock 上找 Python）。
3. 作業的筆記（`NOTE`）與參考連結（`DOCS`）放在第一個文字視窗的最前面；網址不會自動打開，要自己複製。

在這裡 `--check` 只提醒：訊息區列出哪幾條規則沒過，照樣跑。作業在開始跑之前就出錯（例如 `import` 了沒裝的套件），會另開一個文字視窗放 Python 的錯誤訊息。課的 `.venv` 一律裝 matplotlib（在 iPLoT 裡開視窗用，作業的 `REQUIRES` 沒寫也裝）；萬一還是開不了視窗，結果與錯誤放在訊息區。

按作業那一格時，iPLoT 會用程式分析作業檔，**不會在 iPLoT 自己的程序裡執行它**；真的跑是課的 `.venv` 另開的程序。這個程序用你的使用者權限執行作業檔的程式，所以只按你信任的作業。

## 檢查與打包

在課底下按「檢查與打包」，選一份作業（預設是號碼最大的）。

- 有規則沒過（訊息區每條一行 `✗`）：**不打包**，先改好。只有 `⚠` 的（`REQUIRES` 可能漏寫某個套件）照樣打包。
- 過了：產生 `<課>/發出去的/<代號>_學生包.zip`，並在 Finder 顯示。這個 zip 就是發給學生的。解開是一個 `<代號>/` 資料夾：作業檔、`coursework.py`（讓作業跑起來的程式）、`<代號>Space/` 與 `README.txt`。README 寫學生怎麼裝 Python、建 `.venv`、跑作業（macOS 一段、Windows 一段，Windows 未經實機驗證）。

學生包裡不放你的 `.venv`、`.` 開頭的檔、`__pycache__` 與連結；跳過了什麼，訊息區會說。

## `.版本/` 在哪

每一份作業的資料夾裡有一個 `.版本/`：

- 每次「檢查與打包」成功，存一份跟 `發出去的/` 一模一樣的 zip：`<代號>_<日期>_<時間>_學生包.zip`。**不會自動刪。** 學生問「我拿到的是哪一版」、或你改壞了想退回去，都從這裡找。
- 每次按作業那一格，作業檔跟最新一份不一樣就存一份 `<代號>_<日期>_<時間>.py`，留最新 20 份。

`.` 開頭的資料夾在 Finder 預設看不到：打開那份作業的資料夾，按 ⌘⇧.（Command + Shift + 句點）就會出現。要退回某一版，把要的那一份複製回作業資料夾、改回 `<代號>.py` 的名字。這一版沒有按鈕。

## 檔案放在哪、怎麼清掉

課的資料夾（`modules/課程作業/<課的名字>/`）是使用的時候長出來的，不進 git、不進發佈的包；要備份就複製整個資料夾。想拿掉一門課，把它的資料夾丟進垃圾桶。`.venv` 在課的資料夾裡，跟著一起走。

框架本身在 `框架/`、作業類型在 `作業類型/`、範本與範例在 `作業類型/算完畫圖/範本.py` 與 `範例課程/`。

## 環境變數

- `CW_NO_INSTALL=1`：不建 `.venv`、不跑 pip，缺了什麼只說一句。測試用。
- `CW_FROM_IPLOT=1`：iPLoT 另開作業時設的；作業程序看到它就不問、不改檔，結果放進文字視窗。自己在終端機跑作業時不用設。

## 限制

- 需要 Python 3.10 以上（含 pip）；第一次裝套件要網路。
- 現在只有一種作業類型「算完畫圖」。
- 舊格式（`import hk_page` 的檔）不收；那是「科學計算」模組的事。

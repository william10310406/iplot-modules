# Changelog

「頁面」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [Unreleased]

## [0.1.0] - 2026-11-24

模組打開的頁面改由這個模組在那個模組自己的程序裡開（D161）：頁面開著的時候，面板上按別的模組會馬上開始跑，不用等頁面關掉（討論區 #8）。頁面上方那一排（導覽列）照舊，按一格就關掉這一頁、開那個模組。

### 新增
- `ROLE_NAMES`：工作坊裝來的模組要提供頁面視窗、導覽列時，「要允許嗎？」用一般人看得懂的名字說，不再直接寫角色的代號（D166）。
- Dock 上寫開頁面的模組的名字（例如「行事曆」），不是「Python」（`os.app_name`）。

# Changelog

「車車」這個模組的版本紀錄，格式跟 iPLoT 的 CHANGELOG.md 一樣（[Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)）。`tools/publish.py` 取最上面那一節的版本號當工作坊裡的版本，取那一節的第一段當清單頁上的「這一版」。

## [0.1.0] - 2026-10-20

第一版：按一下，一台顏文字的車車從畫面左邊開到右邊；測試工作坊上傳用。

### 新增
- 網頁面板：另開一個視窗看車車開過去，按「再一台」再開一次；關掉視窗後在訊息區留一台。
- 安全模式與 tkinter 面板沒有頁面：直接在訊息區畫出車車。
- 直接在終端機執行 `python3 iplot.py`：車車在終端機裡開過去。

# 行事曆 2：手動驗證（在面板上）

測試與瀏覽器驗證涵蓋了程式與畫面；**下面這些要在真正的 iPLoT 面板上做**，因為它們靠 pywebview 的視窗、Dock 與「互通」另開的程序，測試碰不到。約 15 分鐘。

## 開始之前

1. 記下時間，做完用來證明沒有東西寫到「行事曆 2」以外：

   ```bash
   touch /tmp/iplot-calendar2-marker
   ```

2. **不要把真的 LINE 網址貼在終端機或聊天裡**，只貼在 ⚙ 的輸入框（它是 `type=password`，貼了看不到；貼完立刻清空）。
3. 預期會發生、不是這個模組寫的：「互通」每次跑完模組會同步捷徑，寫它自己的 `modules/互通/捷徑/`、`.lock`、`.sync-error`、`.python`。
4. 日記資料夾跟舊的行事曆是同一個。驗證時**新舊不要同時開著寫同一天**。

## 1. 分開開

1. 面板上雙擊「行事曆」：訊息區「打開行事曆」，一個視窗，標題「行事曆」，Dock 一個**紅色**月曆圖示。
2. 面板上雙擊「行事曆 2」：訊息區「打開行事曆 2」，另一個視窗，標題「行事曆 2」，Dock 多一個**藍色**月曆圖示。兩個都開著。
3. 各再雙擊一次：各自說「…已經開著」並叫到最前面；沒有第三個視窗。
4. 關掉舊的：新的不受影響；再雙擊舊的：能再開。關掉新的：`modules/行事曆 2/.pid` 不見了（舊的 `.pid` 在它自己資料夾，互不干擾）。
5. 從「行事曆 2」上方的模組列：看得到舊的「行事曆」（不會看到「行事曆 2」自己）。

## 2. 沒網址

1. 關掉再打開「行事曆 2」：月、年、日跟舊的一樣；頂端右邊是「LINE 未設定」。
2. ⚙：LINE 區說「還沒設定網址」，「清除」「立刻更新」是灰的。

## 3. 貼網址

1. ⚙ 貼上不合格的：`http://…`、少了 `.json`、一般網頁網址 → 都說「這不是 iPLoT 的網址…請私訊 bot『連上iPLoT』拿網址」，輸入框清空，**訊息裡沒有你貼的字**。
2. 貼真的網址 → 「貼上／更換」：頂端「LINE 更新中…」→「LINE ✓ 時間」；⚙ 顯示 `https://<網域>/j/AbCd…wXyZ.json`（遮過）與上次更新的時間，看不到完整網址。
3. 開 `modules/行事曆 2/設定.json`（用文字編輯器看）：`LINE.url` 在這裡，**只有這裡**；檔案權限 `-rw-------`。

## 4. 看資料

1. 月：有 LINE 事項的日子有淡綠色底、左邊線；活動 ▸、待辦 ☐（未完成）／☑（完成）；我自己有字的日子只多一個「LINE ×N」。
2. 心情：挑一個你在 iPLoT 選了表情、LINE 也有心情的日子 → 顯示**你的**；挑一個你沒選表情的 → 顯示 LINE 的（旁邊小小的 ᴸ）。
3. 年：LINE 的心情是虛線外框，只有事項的是小圓點。
4. 日：LINE 的內容在每個欄位下面的淡綠色唯讀區（點不進去、改不了）；一天有好幾則小記就列好幾行；做了什麼有 details 就縮排附上；私人的有 🔒。
5. LINE 的文字有 `<`、`&` 之類的字：照原樣顯示成文字。

## 5. 失敗的時候

1. 關 Wi‑Fi → ⚙「立刻更新」：頂端變紅色「LINE ⚠」，訊息「連不上 LINE（沒有網路）。顯示的是 … 的快取」，月視圖的 LINE 內容還在。
2. 在 LINE 私訊 bot「重設iPLoT網址」→ 開 Wi‑Fi → 「立刻更新」：訊息「LINE 說找不到：網址可能已經重設，請私訊 bot『連上iPLoT』拿新的」，舊資料還在；翻頁不會一直重試。再貼新網址就恢復。
3. 連按「立刻更新」很多次碰到上限（429）：訊息倒數「…秒後可以再更新」，這段時間按鈕是灰的、不送請求。

## 6. 翻月

翻到預設範圍（今天前 35 天到後 70 天）外的月 → 補抓那個月；翻回來不重抓；翻到今天前後 400 天以外 → 說「LINE 只提供今天前後 400 天的資料」。

## 7. 複製進日記（手動）

1. 挑一天，在「做了什麼」先打幾個字，等它說「已存」。
2. 日檢視底下按「把這天 LINE 的內容複製進我的日記」→ 預覽（每個欄位會接上什麼、心情只填你還沒填的）→「複製進日記」。
3. 原本的字還在最前面，LINE 的接在後面，中間有「── 從 LINE 複製 … ──」。
4. Finder 打開那一天的資料夾 → `.history/`：有**複製之前**的版本，逐字相同。
5. 再按一次：「沒有新的 LINE 內容可以複製」。
6. 把那天勾「公開」再複製：預覽有紅字警告，私人項目被略過。

## 8. 自動複製

1. ⚙ 打開「自動複製」（預設是關的）。隔天（或把這台電腦的日期往後調一天、再重新打開行事曆 2）：訊息說「自動複製了 N 天（略過 …）」，昨天的 LINE 內容已經在日記裡。
2. 關掉開關再打開：不會回頭補抓歷史（只從昨天開始）。
3. 勾了「公開」的日子不會被自動複製。

## 9. 網頁與發佈

按「看網頁」「發佈」：打開產生的網頁，**沒複製過的 LINE 內容不會出現**。

## 10. 清除

⚙「清除」→ 確認：網址與快取都沒了（`modules/行事曆 2/` 裡沒有 `line_cache.json`），LINE 的畫面消失，**已經複製進日記的字原封不動**。

## 做完：證明沒有寫到「行事曆 2」以外

```bash
cd ~/Desktop/iPLoT-v0.6.0
find . -type f -newer /tmp/iplot-calendar2-marker -not -path "./modules/行事曆 2/*" -not -name .DS_Store
```

預期只有「互通」自己同步的檔（`modules/互通/捷徑/…`、`.lock`、`.sync-error`、`.python`）；沒有 `core/`、`ui/`、`lib/`、`modules/行事曆/`、`docs/`、`README.md`、`CHANGELOG.md`、`config.py`、`requirements/`。

## 怎麼重現測試

pytest 與 ruff 是開發用的，不在 iPLoT 裡、不進 `lib/`。裝在暫存資料夾：

```bash
python3 -m venv /tmp/iplot-venv
/tmp/iplot-venv/bin/pip install pytest ruff
cd ~/Desktop/iPLoT-v0.6.0
PYTHONDONTWRITEBYTECODE=1 /tmp/iplot-venv/bin/python -B -m pytest -p no:cacheprovider --basetemp=/tmp/iplot-pytest "modules/行事曆 2/tests"
/tmp/iplot-venv/bin/ruff check --no-cache "modules/行事曆 2"
```

這兩段做完 `modules/行事曆 2/` 裡不會留下 `__pycache__`、`.pytest_cache`、`.ruff_cache`。
